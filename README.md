# teaching-cnn

A Jupyter notebook that trains a convolutional neural network (CNN) to classify
images — built to introduce the basics of neural networks to high schoolers.

The notebook walks through each step with directions, while leaving room for
students to experiment with their own datasets from Kaggle! This was used for Columbia Engineering's SHAPE program for high schoolers as material for the AI elective.

## Getting started

1. Download and then open the notebook in [Google Colab](https://colab.research.google.com/) (no
   setup needed) or locally with Jupyter.
2. Run the cells top to bottom, following the inline directions.

## Suggested classroom activity

Have students change the **number of epochs** and record how accuracy shifts
each time. It's a simple, hands-on way to see overfitting and understand the factors affecting accuracy.

## Learn more

- **[TensorFlow Playground](https://playground.tensorflow.org/)** — an
  interactive visualisation of every part of a neural network. Students can tune
  the hyperparameters on a mock dataset and watch accuracy respond in real time.
- **[MediaPipe Studio](https://google-ai-edge.github.io/mediapipe-samples-web/#/vision/gesture_recognizer)**
  — a library of pre-trained models, including landmarking tools that let
  students see a neural network working live on their webcam.
